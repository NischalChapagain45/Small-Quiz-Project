# 🧠 Console Quiz Game

Welcome to my **very first Python project**! This is a simple, interactive, multiple-choice quiz game played directly in the command line. I built this project to practice basic Python concepts while learning how to code.

## 🚀 Features
* **Interactive Gameplay:** Asks trivia questions and takes real-time keyboard inputs.
* **Instant Feedback:** Tells you if your answer is correct or incorrect after a 1-second suspense delay.
* **Score Tracking:** Keeps track of your correct answers and displays a final score at the end.

## 🛠️ Concepts Learned
By building this quiz game, I practiced:
* Working with data structures like **Tuples** and **Lists**.
* Using `for` loops to iterate through data.
* Implementing conditional logic with `if/else` statements.
* Accepting and cleaning user input using `.upper()`.
* Using built-in modules like the `time` module.

## 📦 How to Run the Project

### Prerequisites
Make sure you have Python installed on your computer. You can download it from [python.org](https://python.org).

### Running the Game
1. **Clone the repository** (or download the script file):
   ```bash
   git clone https://github.com
   ```
2. **Navigate into the project directory**:
   ```bash
   cd YOUR_REPOSITORY_NAME
   ```
3. **Run the script**:
   ```bash
   python quiz_game.py
   ```
